# 🦸‍♂️ TaskHero

**TaskHero** — это веб-приложение, которое помогает родителям мотивировать детей выполнять полезные дела в игровой форме.  
Родитель создает аккаунт, добавляет ребёнка и формирует для него индивидуальный трек с заданиями, наградами и уровнями.  
Дети выполняют задания, зарабатывают **EXP** и **коины**, повышают уровень и кастомизируют своего персонажа.

## 🧠 Основная идея

> Сделать выполнение полезных дел **игрой**, а не обязанностью.

- 👨‍👩‍👧 Родители создают аккаунт, добавляют детей
- 📝 Формируют **трек заданий** (одноразовых и повторяющихся)
- 🎯 Настраивают награды: EXP, коины, бонусы
- 🧒 Дети выполняют задания и отправляют на проверку
- 🏆 Получают опыт, растут в уровне, открывают кастомизацию персонажа

## 🧩 Архитектура проекта

Проект реализован как **мультимодульное монолитное Spring Boot-приложение**.

```bash
task-hero/
│
├── dependency_bom/       # Управление версиями зависимостей
├── common/               # Общие сущности, конфигурации, исключения, аудит
├── user-service/         # Модуль работы с пользователями и детьми (WIP)
├── task-service/         # Модуль управления заданиями (WIP)
└── app/                  # Главный модуль приложения (точка входа)
```
⚙️ Архитектура: Modular Monolith
- Разделение по бизнес-доменам (User, Task, Reward), но общее ядро (common)
- При необходимости может быть вынесено в микросервисы.

## 🧱 Структура модулей

| Модуль           | Назначение                                                                         |
| ---------------- | ---------------------------------------------------------------------------------- |
| `dependency_bom` | Единый BOM для управления версиями зависимостей                                    |
| `common`         | Общие классы: `BaseEntity`, `JpaConfig`, `LoggingAspect`, `GlobalExceptionHandler` |
| `user-service`   | Работа с пользователями, детьми и родителями                                       |
| `task-service`   | Управление заданиями, уровнями, наградами                                          |
| `app`            | Точка входа (Spring Boot Application), объединяющая все модули                     |

## 🚀 Запуск проекта

### 1. Клонирование репозитория 
```bash
git clone https://github.com/<your-username>/task-hero.git
cd task-hero
```
### 2. Сборка проекта
```bash
mvn clean install
```
### 3. Запуск приложения
```bash
cd app
mvn spring-boot:run
```
