О проекте TaskGamer

Gamification-платформа для управления детскими заданиями

TaskGamer — это платформа, которая превращает повседневные задания в увлекательное приключение для детей. Родители создают задания, а дети выполняют их, получая опыт, монеты и прокачивая своего персонажа.

Система геймификации мотивирует детей развивать полезные привычки через игровые механики: уровни, классы персонажей, магазин наград и систему достижений.

Возможности

Для родителей
Создание заданий, шаблоны, библиотека, проверка выполнения, магазин наград
Для детей
Выбор персонажа, выполнение заданий, прокачка уровня, покупки в магазине
Геймификация
Опыт, уровни, классы героев, монеты, магазин, повторяющиеся задания

Технологии

Java 17 Spring Boot 3 Thymeleaf PostgreSQL Liquibase Docker Bootstrap 5
